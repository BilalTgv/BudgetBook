# user stories – budgetbook

1. als angemeldete:r benutzer:in möchte ich eine ausgabe erfassen, damit mein saldo aktuell bleibt
2. als angemeldete:r benutzer:in möchte ich eine einnahme erfassen, damit ich weiß wie viel geld reingekommen ist
3. als angemeldete:r benutzer:in möchte ich meine buchungen bearbeiten, damit ich tippfehler korrigieren kann
4. als angemeldete:r benutzer:in möchte ich eine buchung löschen, mit bestätigung, damit ich keine falschen einträge behalte
5. als angemeldete:r benutzer:in möchte ich meine buchungen nach zeitraum und typ filtern, damit ich schnell was ich suche finde
6. als angemeldete:r benutzer:in möchte ich eine statistik sehen (einnahmen, ausgaben, saldo, pro kategorie), damit ich meinen überblick behalte
7. als admin möchte ich kategorien anlegen, bearbeiten und löschen, damit die mitglieder sinnvolle kategorien zur auswahl haben
8. als benutzer:in möchte ich mich registrieren und einloggen können, damit nur ich auf meine eigenen daten zugreifen kann
